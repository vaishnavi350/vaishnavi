## 🚀 How to Run Locally

### Option 1: Direct Browser Opening
Simply double-click `index.html` or open it with Microsoft Edge, Chrome, or Firefox.

### Option 2: Live Server in VS Code
1. Open the `c:\vaishnavi` folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Click **"Go Live"** in the bottom status bar or right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Python Built-in HTTP Server
```bash
# If Python is installed:
python -m http.server 3000
# Open http://localhost:3000 in your browser
```

## 🌐 Deploying to GitHub Pages (Free Hosting)

1. Create a repository on your GitHub account (`vaishnavi350/portfolio`).
2. Push the files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of developer portfolio"
   git branch -M main
   git remote add origin https://github.com/vaishnavi350/portfolio.git
   git push -u origin main
   ```
3. Go to **Settings** > **Pages** in the GitHub repository.
4. Set **Source** to `Deploy from a branch` and select `main` / `root`.
5. Your portfolio will be live at `https://vaishnavi350.github.io/portfolio/`.
